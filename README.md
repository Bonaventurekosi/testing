# Donated Tissue Explorer

An interactive 3D explainer of four human tissues that tissue banks such as MTF Biologics prepare as grafts: dermis, adipose, amnion and chorion.

For each tissue you can rotate a simplified 3D model, switch between how it looks in the body and as a processed graft, pick out individual parts, and read what it is made of and how surgeons use it.

- `index.html` — open this in a browser (needs internet for the three.js library and fonts).
- `src/app.html` — the page source; run `./build.sh` after editing to regenerate `index.html`.

This is an independent educational page. It is not produced by or affiliated with MTF Biologics and is not medical advice. The models are teaching diagrams and are not to scale.
